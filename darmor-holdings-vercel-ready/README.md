# Darmor Holdings

Luxury real estate website for Darmor Holdings, built with Next.js.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Upload the contents of this project to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Keep **Framework Preset** set to **Next.js**.
4. Keep **Root Directory** blank unless the files are inside a subfolder.
5. Keep the build command and output directory on their default settings.
6. Deploy.

The production build command is `npm run build`.
